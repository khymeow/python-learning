### 目前已练习的主要算法思路

以下记录已经写过或练习过的思路，仍需通过独立复现与解释代码巩固。

**1. 前缀和**

通过累加得到当前位置的累计结果。

代表题目：LeetCode 1480。

**2. 哈希表**

使用 Python 字典实现计数和快速查询。

代表题目：LeetCode 1207、LeetCode 1。

其中，「两数之和」从最初的双重循环解法，优化为使用字典查找补数的平均 O(n) 解法。

集合的成员判断和去重也已练习。LeetCode 217「存在重复元素」使用集合记录已出现的数字，发现重复时提前返回；平均时间复杂度为 O(n)，额外空间复杂度为 O(n)。

**3. 双指针**

利用两个索引控制遍历范围，通过合理移动指针减少重复计算。

代表题目：LeetCode 11。

「盛最多水的容器」从最初的 O(n²) 双重循环解法，优化为 O(n) 的双指针解法。

LeetCode 283「移动零」使用同向双指针，依次写入非零元素并将末尾补零，在 O(n) 时间、O(1) 额外空间内原地修改数组。

LeetCode 167「两数之和 II — 输入有序数组」利用数组有序的特点，从两端移动指针查找目标和，时间复杂度为 O(n)，额外空间复杂度为 O(1)。

**4. 栈的基础应用**

使用栈的后进先出特性处理括号匹配，结合字典检查括号类型。

代表题目：LeetCode 20「有效的括号」，时间复杂度为 O(n)，额外空间复杂度为 O(n)。

当前状态：**已练习基础应用，仍需巩固。** 后续继续练习栈的操作、匹配逻辑、边界条件及独立实现；单调栈等进阶应用尚未系统学习。

**5. 队列与双端队列**

已使用 `collections.deque` 完成 LeetCode 933「最近的请求次数」，并练习过普通 Python 动态任务队列。接触了 `deque` 初始化、`append()` 入队、`popleft()` 移除队首，以及通过 `while` 维护滑动时间窗口。

已经比较列表 `pop(0)` 与 `deque.popleft()` 的复杂度区别，并接触了第 933 题的均摊时间复杂度分析。

当前状态：**基础操作已练习，仍需巩固。** 队列在第 933 题的时间窗口和第 1971 题的 BFS 中已有实际应用，后续继续练习独立实现。

**6. 图、邻接表与 BFS**

已完成 LeetCode 1971「寻找图中是否存在路径」。使用 `range(n)` 初始化邻接表，为无向边记录两个方向，用 `deque([source])` 和 `visited = {source}` 初始化搜索，通过出队、检查终点、标记邻居和入队完成 BFS。

本题是在多轮指导和调试后完成的。过程中曾遇到整数与可迭代对象区分、邻接表初始化和赋值、遗漏无向边反方向、队列初始化与方法调用，以及多个数据结构组合使用等问题。

当前状态：**图与 BFS：已完成一道基础可达性题目，掌握基本实现框架；邻接表构建、数据结构组合和独立调试仍需专项巩固。** 目前仍需练习不看完整答案独立重写，不能据此认定已经熟练掌握图算法。

已独立编写 [LeetCode 752「打开转盘锁」](https://leetcode.cn/problems/open-the-lock/) 的单向 BFS 最短路径解法：从 `"0000"` 出发，动态生成每个状态的 8 个相邻状态，使用队列按最短距离逐层搜索，跳过死亡状态和已访问状态。时间复杂度为 O(10⁴)，空间复杂度为 O(10⁴)。本次记录了队列与集合初始化、`append()` 与 `extend()`、元组拆包、距离记录和边界判断顺序等易错点，详见题解；继续巩固状态建模与 BFS，不将完成题目等同于全面掌握。
