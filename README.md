### 目前掌握的主要算法思路

**1. 前缀和**

通过累加得到当前位置的累计结果。

代表题目：LeetCode 1480。

**2. 哈希表**

使用 Python 字典实现计数和快速查询。

代表题目：LeetCode 1207、LeetCode 1。

其中，「两数之和」从最初的双重循环解法，优化为使用字典查找补数的平均 O(n) 解法。

**3. 双指针**

利用两个索引控制遍历范围，通过合理移动指针减少重复计算。

代表题目：LeetCode 11。

「盛最多水的容器」从最初的 O(n²) 双重循环解法，优化为 O(n) 的双指针解法。

LeetCode 283「移动零」使用同向双指针，依次写入非零元素并将末尾补零，在 O(n) 时间、O(1) 额外空间内原地修改数组。

## 六、如何运行

- Python 3
- Git（用于版本管理）

当前题解使用 Python 标准功能，无需额外安装第三方依赖。

### 克隆仓库

```bash
git clone https://github.com/khymeow/python-learning.git
cd python-learning
```

例如运行 LeetCode 11：

```bash
python leetcode_11.py
```

也可以运行其他题目：

## 七、学习与代码提交方式

本仓库坚持**独立解题为主、AI 辅助工程管理**的原则。

学习流程：

1. 理解 Python 知识点或算法题目
2. 独立分析问题并编写第一版代码
3. 运行测试、检查边界条件
4. 分析时间复杂度和空间复杂度
5. 尝试优化算法，理解优化原理
6. 完成 LeetCode 在线提交
7. 使用 Codex 整理题解并更新 GitHub

### Codex 的职责

Codex 主要负责：

- 整理已有题解
- 添加题目说明和必要注释
- 运行测试
- 维护代码文件
- 执行 Git commit 和 Git push
- 根据实际学习进度更新 README

今后新增 LeetCode 题解时，同步更新 README 中的题目记录和项目结构；学习进度发生变化时，按照已确认的最新学习内容更新状态，不自动把计划中的知识标记为已掌握。

Codex 不应在未获要求的情况下替代独立解题，也不应随意修改原有算法思路。

具体工作规则见 [AGENTS.md](AGENTS.md)。
