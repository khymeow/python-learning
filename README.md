## 如何运行

### 环境要求

- Python 3
- Git（用于版本管理）

当前题解只使用 Python 标准功能，无需安装第三方依赖。

### 运行示例

克隆仓库：

```bash
git clone https://github.com/khymeow/python-learning.git
cd python-learning
```

运行 LeetCode 1480：

```bash
python leetcode_1480.py
```

运行 LeetCode 1672：

```bash
python leetcode_1672.py
```
